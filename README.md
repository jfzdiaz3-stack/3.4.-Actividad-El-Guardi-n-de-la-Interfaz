# 3.4.-Actividad-El-Guardi-n-de-la-Interfaz

## Descripción

Aplicación web desarrollada con HTML, CSS y JavaScript que permite personalizar el aspecto visual de la página web mediante cookies.

## Funcionalidades

- Introducción de nombre de usuario.
- Selección de color de fondo.
- Cambio entre tema claro y oscuro.
- Generación dinámica de contenido con JavaScript.
- Almacenamiento de preferencias mediante cookies.
- Recuperación automática de preferencias al recargar la página.
- Restablecimiento completo de la interfaz.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
